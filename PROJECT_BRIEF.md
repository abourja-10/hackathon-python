# PROJECT BRIEF — CampusBoard

## 1. Presentazione del progetto

**CampusBoard** è una bacheca digitale sviluppata nell'ambito del Python Innovation Hackathon.

Il progetto nasce con l'obiettivo di migliorare la comunicazione e la collaborazione all'interno della comunità universitaria, offrendo uno strumento per gestire oggetti ritrovati e segnalazioni relative alla vita del campus.

## 2. Problema da risolvere

Nella comunità universitaria può essere difficile condividere informazioni riguardanti oggetti smarriti o ritrovati e problemi presenti negli spazi comuni.

Le informazioni possono essere disperse o difficili da consultare.

CampusBoard propone una soluzione digitale centralizzata che consente di raccogliere, organizzare e consultare queste informazioni.

## 3. Destinatari

Il progetto è rivolto principalmente a:

- Studenti universitari.
- Membri della comunità universitaria.
- Persone che desiderano segnalare problemi o consultare informazioni utili nel campus.

## 4. Obiettivi

Gli obiettivi principali sono:

- Centralizzare le informazioni in una bacheca digitale.
- Semplificare la registrazione di oggetti ritrovati e segnalazioni.
- Consentire la ricerca e il filtraggio delle informazioni.
- Gestire gli stati delle segnalazioni.
- Conservare i casi conclusi in un archivio.
- Permettere l'esportazione dei dati.
- Rendere le informazioni accessibili attraverso un'interfaccia web.

## 5. MVP — Minimum Viable Product

La versione iniziale del progetto comprende:

- Applicazione Python a riga di comando.
- Registrazione di oggetti ritrovati e segnalazioni.
- Ricerca delle informazioni.
- Aggiornamento e chiusura dei casi.
- Consultazione dei casi aperti e archiviati.
- Persistenza dei dati tramite JSON.
- Esportazione dei dati.
- Interfaccia web per la visualizzazione delle informazioni.

## 6. Motivazione della soluzione

Python è stato scelto per implementare la logica applicativa e la gestione dei dati.

La persistenza tramite JSON permette di conservare le informazioni senza richiedere un database esterno.

Il frontend web consente una consultazione più intuitiva rispetto alla sola interfaccia terminale.

Il progetto combina quindi una gestione funzionale tramite CLI con una visualizzazione accessibile attraverso il browser.

## 7. Tecnologie utilizzate

- Python
- JSON
- Node.js
- Express
- HTML
- CSS
- JavaScript
- Git e GitHub

## 8. Risultato atteso

Realizzare una soluzione funzionante e facilmente utilizzabile per organizzare le informazioni della comunità universitaria, dimostrando l'applicazione delle competenze di programmazione Python e sviluppo software.
